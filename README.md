---

## Что это

GraphA анализирует исходный код JavaScript и TypeScript проектов и строит граф зависимостей между файлами. Вместо того чтобы вручную разбираться кто что импортирует — вы видите всю архитектуру сразу.

**Для кого:** разработчики которые хотят понять незнакомый проект, найти проблемные места перед рефакторингом или объяснить архитектуру команде.

---

## Возможности

- **AST-парсинг** через tree-sitter — точнее регулярных выражений, не находит импорты в комментариях
- **Четыре режима визуализации** — силовой, иерархический (Dagre), радиальный, кластеризация Маркова (MCL)
- **Метрики для каждого файла** — fan-in, fan-out, betweenness centrality, циклические зависимости
- **Циклы выделяются красным** — алгоритм Косараджу (SCC)
- **Экспорт в SVG** — векторный формат, открывается в Figma и Illustrator
- **Работает с большими репозиториями** — протестировано на facebook/react (4364 файла)

## Быстрый старт

### Требования
- Python 3.11+
- Node.js 18+
- Git

### Бэкенд

```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### Фронтенд

```bash
cd frontend
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

## Как пользоваться

1. Вставьте ссылку на публичный GitHub-репозиторий в формате `https://github.com/user/repo.git`
2. Нажмите `→` и дождитесь построения графа (2–30 секунд в зависимости от размера)
3. Кликайте на узлы — справа появятся метрики файла
4. Переключайте режимы компоновки в настройках
5. Экспортируйте граф в SVG через кнопку «Экспорт»

## Метрики

| Метрика | Норма | Внимание | Критично |
|---|---|---|---|
| Fan-in | 1–10 | 11–20 | > 20 |
| Fan-out | 1–7 | 8–15 | > 15 |
| Centrality | < 0.01 | 0.01–0.05 | > 0.05 |
| Циклы | 0 | — | > 0 |

Значения ориентировочные — для каждого проекта норма может отличаться в зависимости от его размера и архитектуры.

---


## Ограничения

- Псевдонимы путей (`@/components`) из `tsconfig.json` не разрешаются
- Межпакетные зависимости в монорепозиториях видны частично
- Динамические импорты с вычисляемыми путями (`import(variable)`) не анализируются
